# People Portal Web UI

This project is part of an Nx monorepo. The local `package.json` scripts have been migrated to Nx targets. 

You should execute tasks for this project via the Nx CLI from the root of the workspace.

## Common Commands

* **Start Development Server**: `nx serve pplui`
* **Build Project**: `nx build pplui`
* **Preview Production Build**: `nx preview pplui`
* **Run Linter**: `nx lint pplui`
* **Run Tests**: `nx test pplui`
* **Run Tests (Watch Mode)**: `nx test-watch pplui`
* **Run Tests (UI Mode)**: `nx test-ui pplui`

*Note: Make sure you run these commands from the root of the monorepo.*
